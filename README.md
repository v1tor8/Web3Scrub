Streamlines decentralized data validation through intelligent contract management on a blockchain node management framework platform.

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/Web3Scrub.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Web3Scrub is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
